# Интерактивное демо

На текущий момент существует несколько реализаций демо-чатов, размещённых [здесь](https://mobilon-dev.github.io/chotto-demo/). Навигация между реализациями осуществляется посредством контекстного меню в заголовке. Реализованы следующие чаты:

- [`Chat 00`](https://mobilon-dev.github.io/chotto-demo/#/0) - переписка между собой двух человек, обычный диалог. Представлено два чата в FloatContainer, основанных на FeedLayout. 
- [`Chat01`](https://mobilon-dev.github.io/chotto-demo/#/1) - переписка между менеджером и клиентами компании. Все чаты основаны на FloatContainer, интерфейс менеджера использует BaseLayout, интерфейс клиента использует FeedLayout.
- [`Chat02`](https://mobilon-dev.github.io/chotto-demo/#/2) - переписка между менеджером и клиентами компании, пример работы с адаптивными шаблонами WhatsApp Business API и взаимодействия через разные каналы связи.
- [`Chat03`](https://mobilon-dev.github.io/chotto-demo/#/3) - реализация поиска сообщений в чате. Представлены разные варианты размещения основных компонентов поиска в зависимости от доступного пространства в выбранном layout.
- [`Chat04`](https://mobilon-dev.github.io/chotto-demo/#/4) - пример чата в AdaptiveExtendedLayout. Имеется возможность изменения размера контейнера для демонстрации адаптивности.
- [`Chat05`](https://mobilon-dev.github.io/chotto-demo/#/5) - пример мультидиалогового общения с клиентом - диалоги могут отличаться атрибутами (каналом связи), назначением и иными параметрами. Каждый из диалогов является полноценным чатом, привязанным к одному контакту.
- [`Chat06`](https://mobilon-dev.github.io/chotto-demo/#/6) - демонстрация возможностей аудио- и видеозаписи. Доступны запись, прослушивание и отправка аудио- и видеосообщений.
- [`Chat07`](https://mobilon-dev.github.io/chotto-demo/#/7) - переписка с GigaChat. [GigaChat](https://giga.chat/) - большая языковая модель ИИ от Сбера. Также существует приложение [GigaChat API Explorer](https://mobilon-dev.github.io/gigachat-api-explorer/) для изучения возможностей API, предоставляемых для работы с моделью.
- [`Chat08`](https://mobilon-dev.github.io/chotto-demo/#/8) - рестайлинг по условию пользователя. Представлена ситуация использования одновременно двух каналов для диалога с клиентом: через telegram и whatsapp. В зависимости от диалога используется разное цветовое оформление элементов чата.
- [`Chat09`](https://mobilon-dev.github.io/chotto-demo/#/9) - пример чата в FloatContainer с BaseLayout. Демонстрирует мультидиалоговое общение с клиентом - диалоги могут отличаться атрибутами, назначением и иными параметрами. Каждый из диалогов является полноценным чатом, привязанным к одному контакту.
- [`Chat10`](https://mobilon-dev.github.io/chotto-demo/#/10) - пример чата в AdaptiveExtendedLayout с расширенными возможностями. Включает поиск сообщений, SideBar для фильтрации чатов, поддержку WhatsApp Business API шаблонов и выбор каналов связи. Имеется возможность изменения размера контейнера для демонстрации адаптивности - компоненты автоматически перестраиваются в зависимости от доступного пространства.
